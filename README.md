# Код времени — решения участников хакатона 2026

Этот репозиторий предназначен для сбора ML-решений команд хакатона **«Код времени»**.

Просим каждую команду загрузить код, использованный для обучения своей ML-модели.

## Что необходимо загрузить

Создайте отдельную папку с названием вашей команды и добавьте в неё:

- Код обучения модели (`.py` или `.ipynb`).
- `requirements.txt` — список используемых библиотек (по возможности).
- `README.md` — краткое описание решения и инструкция по запуску (по возможности).

**Важно:** не загружайте исходные датасеты, большие файлы моделей, пароли и токены доступа.

## Как отправить решение

1. Сделайте **Fork** этого репозитория в свой GitHub-аккаунт (кнопка **Fork** в правом верхнем углу).
2. В своей копии репозитория создайте папку `solutions/название-команды`.
3. Загрузите в неё файлы вашего решения и сохраните изменения (**Commit changes**).
4. Нажмите **Contribute → Open pull request**.
5. Убедитесь, что Pull Request направлен в исходный репозиторий, в ветку `master`.
6. В названии Pull Request укажите название вашей команды и нажмите **Create pull request**.

**От каждой команды ожидается один Pull Request.**

## Структура репозитория

```text
solutions/
├── team-{NAME1}/
│   ├── train.ipynb
│   ├── requirements.txt
│   └── README.md
├── team-{NAME2}/
│   ├── train.py
│   └── README.md
└── ...
```
